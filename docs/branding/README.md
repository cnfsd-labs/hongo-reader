# Branding

- `app-icon-artwork.webp`: the app icon artwork (1024×1024). The launcher icon
  (`app/src/main/res/drawable-nodpi/ic_launcher_art.png`, 432×432 = 108dp at xxxhdpi) is composed
  from it so the book fits Android's adaptive-icon safe zone: the artwork at 66% over a blurred
  copy of its own gradient. Use the artwork directly for the Play Store's 512×512 icon.
